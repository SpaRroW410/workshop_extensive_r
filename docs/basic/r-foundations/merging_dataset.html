Merging Datasets in R

This module explains how to combine datasets by rows, columns, and with joins.

Append rows with rbind()

data1 <- data.frame(ID = 1:3, Name = c("Alice", "Bob", "Charlie"), Age = c(23, 35, 28))
data2 <- data.frame(ID = 4:6, Name = c("David", "Eva", "Frank"), Age = c(45, 30, 40))
merged_rows <- rbind(data1, data2)
merged_rows
  ID    Name Age
1  1   Alice  23
2  2     Bob  35
3  3 Charlie  28
4  4   David  45
5  5     Eva  30
6  6   Frank  40

Combine columns with cbind()

data1 <- data.frame(ID = 1:3, Name = c("Alice", "Bob", "Charlie"))
data2 <- data.frame(Age = c(23, 35, 28), Height = c(165, 180, 175))
merged_columns <- cbind(data1, data2)
merged_columns
  ID    Name Age Height
1  1   Alice  23    165
2  2     Bob  35    180
3  3 Charlie  28    175

Joins with dplyr

library(dplyr)

Attaching package: 'dplyr'
The following objects are masked from 'package:stats':

    filter, lag

    intersect, setdiff, setequal, union
data1 <- data.frame(
  ID = 1:5,
  Name = c("Alice", "Bob", "Charlie", "David", "Eva")
)
data2 <- data.frame(
  ID = c(2, 3, 5, 6),
  Score = c(85, 90, 88, 92)
)

inner_join(data1, data2, by = "ID")
  ID    Name Score
1  2     Bob    85
2  3 Charlie    90
3  5     Eva    88
left_join(data1, data2, by = "ID")
  ID    Name Score
1  1   Alice    NA
2  2     Bob    85
3  3 Charlie    90
4  4   David    NA
5  5     Eva    88
right_join(data1, data2, by = "ID")
  ID    Name Score
1  2     Bob    85
2  3 Charlie    90
3  5     Eva    88
4  6    <NA>    92
full_join(data1, data2, by = "ID")
  ID    Name Score
1  1   Alice    NA
2  2     Bob    85
3  3 Charlie    90
4  4   David    NA
5  5     Eva    88
6  6    <NA>    92

These join types are useful for combining medical records, survey forms, and measurement datasets.

Stack rows with bind_rows()

bind_rows() (dplyr) does the same job as rbind(): tables with the same columns, different people.

library(dplyr)
round1 <- data.frame(id = 1:3, sbp = c(120, 135, 142))
round2 <- data.frame(id = 4:6, sbp = c(128, 150, 118))
bind_rows(round1, round2)
  id sbp
1  1 120
2  2 135
3  3 142
4  4 128
5  5 150
6  6 118

Why not cbind() for the same people?

cbind() pastes by position and never checks who is who. If the two tables are sorted differently, the columns are silently mixed up. Join by a key such as id instead.

Duplicate keys multiply rows

patients <- data.frame(id = 1:5, name = c("Asha", "Bina", "Chetan", "Dev", "Esha"))
labs     <- data.frame(id = c(3, 3, 5), hba1c = c(7.1, 6.8, 8.0))   # id 3 was tested twice
nrow(patients)
[1] 5
nrow(left_join(patients, labs, by = "id"))   # 6: patient 3 appears twice
[1] 6
count(labs, id)                                # check the key before joining
  id n
1  3 2
2  5 1

A left join keeps every patient, but a patient who matches two lab rows appears twice. Count rows before and after every join, and check that the key is unique in the table you join to.

Reshape: wide and long

The same blood pressures can be stored wide (one row per person, one column per measurement) or long (one row per person and measurement). ggplot2 and most models want long data.

library(tidyr)
wide <- data.frame(id = 1:3, sbp = c(128, 142, 135), dbp = c(82, 90, 85))
long <- pivot_longer(wide, cols = c(sbp, dbp), names_to = "measure", values_to = "mmHg")
long
# A tibble: 6 × 3
     id measure  mmHg
  <int> <chr>   <dbl>
1     1 sbp       128
2     1 dbp        82
3     2 sbp       142
4     2 dbp        90
5     3 sbp       135
6     3 dbp        85
pivot_wider(long, names_from = measure, values_from = mmHg)   # and back again
# A tibble: 3 × 3
     id   sbp   dbp
  <int> <dbl> <dbl>
1     1   128    82
2     2   142    90
3     3   135    85

pivot_longer() never changes the number of values: 3 people × 2 measurements = 6 rows.

Self-check quiz

patients has 5 rows; labs has 3 rows, two of them for patient 3. How many rows does left_join(patients, labs, by = "id") return?

  • 5
  • 3
  • 6
  • 8

Why is cbind() risky for putting together two tables about the same patients?

  • It cannot combine tables with more than two columns
  • It pastes rows by position and never checks the id
  • It drops patients missing from one of the tables
  • It turns numeric columns into character columns

Which join keeps every row of both tables, with NA where there is no match?

  • inner_join()
  • left_join()
  • semi_join()
  • full_join()

What should you check before joining a lab table to a patient table?

  • Whether the id is unique in the table you join to
  • Whether both tables were saved in the same file format
  • Whether the two tables have the same number of columns
  • Whether the id column is stored as text

Systolic and diastolic BP are two columns. Which function gives one row per person and measurement?

  • pivot_wider()
  • pivot_longer()
  • bind_rows()
  • separate_wider_delim()
