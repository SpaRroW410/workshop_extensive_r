Basic Track

Step 1 of the self-study path. Start here if you are new to R: you will set up R, wrangle a dataset, draw your first plots, choose a statistical test and write a reproducible report.

🗺️ Play as you learn. This track is Region 1 · Basics of Dungeons & Dataframes. Take the pre-test, read a step below, then clear the matching world. Open the game →

🗓️ Self-study plan

Work through the steps in order. Every page ends with a self-check quiz, and each step has a lab (an R script with blanks to fill in; it reads the NCD survey). Keep the Basic cheat sheet open. Tick a step when you have finished it; ticks are saved in this browser.

  1. Set up R and write your first lines

    Getting Started: install R and RStudio, objects, vectors and data frames. Lab: b1_first_script.R.

  2. Wrangle a dataset

    Data Wrangling (Tidyverse), then Merging Datasets. Practise with the Practice Slides. Labs: b2_tidy_data.R · b3_joining.R.

  3. Draw your first plots

    Grammar of Graphics, then copy and adapt examples from the Basic Plot Gallery. Lab: b4_first_plots.R.

  4. Choose and run a statistical test

    Test Selection Guide, then ggstatsplot — Intro to plot a test and its result together. Lab: b5_which_test.R.

  5. Meet regression

    Regression Analysis: a first look. The Regression track covers it in depth.

  6. Write it up

    Quarto Basics: turn your code and results into a report. Lab: b6_first_report.R.

  7. Check yourself and move on

    Take the Region 1 post-test in the game. At 70% or more, continue with the Moderate track (Step 2 on the main page).

🎯 What you will be able to do

  • Use R to import, clean and reshape data
  • Build clear basic plots with ggplot2
  • Pick a suitable statistical test and read its output
  • Produce a reproducible report with Quarto
