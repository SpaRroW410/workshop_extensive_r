Setup

Contour Plot

Code 
ggplot(health_data, aes(x = BMI, y = SysBP_0m)) +
  geom_density_2d_filled(alpha = 0.7) +
  geom_point(size = 0.5, alpha = 0.3) +
  scale_fill_viridis_d(option = "plasma") +
  labs(title = "2D Density: BMI vs Blood Pressure",
       x = "BMI", y = "Systolic BP") +
  theme_minimal()

Shows where patients concentrate: brighter bands = more patients. With 200 points the contours are rough; they pay off with thousands.

Parallel Coordinates

Code 
library(GGally)
health_subset <- health_data %>%
  select(Age, BMI, SysBP_0m, Cholesterol, BloodSugar) %>%
  na.omit()

ggparcoord(health_subset, columns = 1:5,
           scale = "uniminmax",
           alphaLines = 0.3) +
  labs(title = "Parallel Coordinates: Health Metrics") +
  theme_minimal()

Each line = one patient across multiple variables

3D Surface

Code 
library(plotly)
d <- health_data %>% filter(!is.na(BMI), !is.na(SysBP_0m))
dens <- MASS::kde2d(d$BMI, d$SysBP_0m, n = 50)      # 2D kernel density on a 50 x 50 grid
plot_ly(x = dens$x, y = dens$y, z = t(dens$z)) %>%
  add_surface() %>%
  layout(scene = list(xaxis = list(title = "BMI"), yaxis = list(title = "Systolic BP"),
                      zaxis = list(title = "Density")))

Drag to rotate. The same density as the contour plot: 3D looks striking, but contours are easier to read exactly.

Hexbin Plot

Code 
ggplot(health_data, aes(x = BMI, y = SysBP_0m)) +
  geom_hex(bins = 30) +
  scale_fill_viridis_c(option = "inferno", trans = "log10") +
  labs(title = "Hexbin Plot: Large Dataset Visualization",
       fill = "Count (log10)") +
  theme_minimal()

Better than a scatter plot for 1000+ points; with 200 patients most bins hold 1 or 2.

Correlation Matrix

Code 
library(ggcorrplot)
cor_matrix <- health_data %>%
  select(Age, BMI, SysBP_0m, DiaBP_0m, 
         Cholesterol, BloodSugar) %>%
  cor(use = "complete.obs")

ggcorrplot(cor_matrix, type = "lower",
           lab = TRUE, lab_size = 3,
           colors = c("#DC0000", "white", "#00A087"))

Quick overview of all pairwise correlations. Here every |r| is below 0.12: in this simulated dataset the variables were generated almost independently, which the scatter plots on the earlier slides also show.
