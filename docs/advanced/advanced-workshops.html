Advanced Workshops

Nine modules. Each has five slide decks with a self-check quiz, five R labs and a two-page cheat sheet.

Every module runs on its own synthetic dataset. Open a session to see the slides; the lab file named on the lab slide is in the downloads on the welcome page. Quiz scores are kept in your browser and can be saved as a text file from the last quiz slide.
