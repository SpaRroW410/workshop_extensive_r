References

The works the tracks and workshops are built on, grouped by topic. Under each entry: where on the site it is used. Journal articles and books with a DOI were checked against their Crossref records; software citations come from each package’s own citation(), for the versions used to build the site (November 2026).

TipCiting R and packages in your own work

Run citation() for R and citation("package") for each package you used, and report the versions (sessionInfo()). The Regression workshop, Session 6, shows a methods paragraph that does this.
