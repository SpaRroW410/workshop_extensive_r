Regression Analysis

Regression models describe and quantify the relationship between an outcome and one or more predictors. This module builds up in tiers — start with a single predictor, then add predictors, then move on to diagnostics and logistic regression.

data <- data.frame(
  age = rnorm(100, 50, 10),
  blood_pressure = rnorm(100, 120, 15),
  treatment = sample(c("A", "B"), 100, replace = TRUE)
)

model_simple <- lm(blood_pressure ~ age, data = data)
summary(model_simple)

ggplot(data, aes(x = age, y = blood_pressure)) +
  geom_point(alpha = 0.6) +
  geom_smooth(method = "lm", se = TRUE) +
  labs(
    title = "Blood Pressure vs Age",
    x = "Age", y = "Blood Pressure"
  )
`geom_smooth()` using formula = 'y ~ x'

geom_smooth(method = "lm") draws the same fitted line as lm(), with a shaded confidence band around it.

Multiple Regression

Adding more predictors lets the model account for other sources of variation at the same time.

library(gtsummary)

model <- lm(blood_pressure ~ age + treatment, data = data)
summary(model)
