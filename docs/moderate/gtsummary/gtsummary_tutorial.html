  • by = splits the columns by group; add_overall() adds a total column.
  • statistic = chooses the summary: "{mean} ({sd})" for roughly symmetric variables, "{median} ({p25}, {p75})" for skewed ones.
  • missing_text shows how many values are missing for each variable; do not hide them.
  • add_p() picks a test for each variable (Wilcoxon, t-test, chi-square, Fisher) and footnotes which one.

Reading Table 1

  • Table 1 describes the sample; it is not where the findings go (models and effects belong in later tables).
  • Give n (%) for categories and mean (SD) or median (IQR) for numbers; say which in the footnote.
  • In a randomised trial, do not report p-values for baseline differences: any difference is by chance. Use standardised differences if you need a check.
  • In an observational study, p-values for exposure groups are descriptive; the size of the difference matters more than the p.
  • Report missing counts, and the number analysed.
  • Export for a paper with as_flex_table() (Word) or as_gt() (HTML/PDF).

What add_p() does by default

Variable 2 groups 3 or more groups
Number Wilcoxon rank-sum (Mann–Whitney), whatever the distribution Kruskal–Wallis
Category chi-square without Yates’ correction if every expected count is ≥ 5, otherwise Fisher’s exact same rule

The default for categories is stricter than Cochran’s rule (Fisher as soon as any expected count is below 5), which is safe. The default for numbers never uses a t-test: you choose that yourself, below.

A pipeline that chooses the test for each variable

The rule, the same as in the Statistical Analysis workshop (Session 2): a number is analysed parametrically (mean (SD), t-test or Welch ANOVA) when it is roughly symmetric in every group (|skewness| < 1) and either the group has at least 30 people or, in a smaller group, Shapiro–Wilk does not reject normality; otherwise rank-based (median (IQR), Mann–Whitney or Kruskal–Wallis). A category gets chi-square when at least 80% of expected counts are ≥ 5 and none is below 1 (and, in a 2 × 2 table, none below 5); otherwise Fisher.

skewness <- function(x) { x <- x[!is.na(x)]; mean((x - mean(x))^3) / sd(x)^3 }

# One row per variable: the evidence, the decision, the test and the summary to show
choose_tests <- function(data, by, continuous, categorical) {
  k <- n_distinct(data[[by]])
  cont <- map(continuous, \(v) {
    g <- map(split(data[[v]], data[[by]]), \(x) x[!is.na(x)])
    n <- lengths(g); sk <- map_dbl(g, skewness)
    sw <- map_dbl(g, \(x) if (length(x) < 30) shapiro.test(x)$p.value else NA)
    tibble(variable = v, smallest_n = min(n), largest_skew = max(abs(sk)),
           shapiro_small_groups = if (all(is.na(sw))) NA else min(sw, na.rm = TRUE),   # NA: no group under 30
           parametric = all(abs(sk) < 1 & (n >= 30 | sw > 0.05), na.rm = TRUE))
  }) |> list_rbind() |>
    mutate(test = case_when(parametric & k == 2 ~ "t.test", parametric ~ "oneway.test",
                            k == 2 ~ "wilcox.test", TRUE ~ "kruskal.test"),
           statistic = if_else(parametric, "{mean} ({sd})", "{median} ({p25}, {p75})"))
  cat <- map(categorical, \(v) {
    e <- suppressWarnings(chisq.test(table(data[[v]], data[[by]]))$expected)
    tibble(variable = v, table = paste(dim(e), collapse = " x "),
           smallest_expected = min(e), pct_below_5 = 100 * mean(e < 5),
           test = if_else((all(dim(e) == 2) & min(e) < 5) | mean(e < 5) > 0.2 | min(e) < 1,
                          "fisher.test", "chisq.test.no.correct"))
  }) |> list_rbind()
  list(continuous = cont, categorical = cat)
}

  • With only 27 adults in the diabetes group, Shapiro–Wilk also decides for that group. Age fails (skewness 1.0, and Shapiro–Wilk p = 0.02 among the diabetics): Mann–Whitney, median (IQR). Height, weight and glucose pass: Welch t, mean (SD).
  • Glucose looks very skewed in the whole sample (skewness 3.6, workshop Session 2), but that is two groups mixed together: within each group it is roughly symmetric, and that is what the t-test needs. Welch copes with the very different SDs (14 vs 58 mg/dL).
  • Known hypertension (2 × 2, an expected count of 2.6) and marital status (a third of expected counts below 5) go to Fisher; wealth (exactly 20% below 5, none below 1) stays with chi-square.
  • The footnotes name the test used for each row, so the methods section can say: “Numbers were compared with Welch’s t-test when roughly symmetric (|skewness| < 1, and Shapiro–Wilk p > 0.05 in groups under 30) and with the Mann–Whitney U test otherwise; categories with the chi-square test, or Fisher’s exact test when expected counts were small. p-values were adjusted with Holm’s method.”
  • add_q() adds Holm-adjusted p-values: a Table 1 makes many comparisons at once.

ImportantA rule chosen from the data must be fixed in advance

Choosing each test by looking at the data is common in Table 1 and acceptable when the rule is written in the protocol or analysis plan and reported. Do not try both tests and keep the smaller p. For the main comparison of a study, decide the test from the design and the known behaviour of the variable (length of hospital stay and triglycerides are skewed in every study), not from this pipeline.

Your own test: chi-square test for trend

For an ordered category (education, wealth) against a yes/no outcome, a test for trend asks one sharper question than the ordinary chi-square (“does the percentage rise or fall across the levels?”). gtsummary has no built-in trend test, but add_p() accepts any function that returns a p-value and a method name:

trend_test <- function(data, variable, by, ...) {
  tab <- table(data[[variable]], data[[by]])
  res <- prop.trend.test(tab[, "Yes"], rowSums(tab))       # Cochran–Armitage chi-square for trend
  tibble::tibble(p.value = res$p.value, method = "Chi-square test for trend")
}

Checklist for a table with p-values

  • The summary matches the test: mean (SD) with t-test or ANOVA, median (IQR) with rank-based tests.
  • The rule for choosing tests is written in the methods; the footnotes name each test.
  • Paired or clustered data use group =; never compare visits as independent groups.
  • Report missing values (missing_text); tests use the people with data for that variable.
  • Many comparisons: adjust (add_q()) or call them descriptive.
  • Show sizes, not only p: add_difference() or add_ci().
  • Randomised trial baseline: no p-values; standardised differences if needed.
  • What gtsummary cannot do (assumption checks, post hoc tests, 3+ repeated measures, correlation, agreement) goes in the text or a separate table, with its own effect size and CI.
