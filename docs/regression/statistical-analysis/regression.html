Regression Analysis

Regression models describe and quantify the relationship between an outcome and one or more predictors. This module builds up in tiers — start with a single predictor, then add predictors, then move on to diagnostics and logistic regression.

Regression Diagnostics

A fitted model is only trustworthy once its assumptions have been checked.

par(mfrow = c(2, 2))
plot(model)
# Residuals vs fitted, and a normal Q-Q check
qqnorm(residuals(model))
qqline(residuals(model), col = "red")

Watch for: non-random patterns in residuals-vs-fitted (non-linearity), points far off the Q-Q line (non-normal residuals), and high-leverage points in the residuals-vs-leverage panel.

Logistic Regression

When the outcome is binary rather than continuous, use glm() with a binomial family instead of lm().

data$outcome <- sample(c("Improved", "Not Improved"), 100, replace = TRUE)
data$outcome_bin <- ifelse(data$outcome == "Improved", 1, 0)

model_log <- glm(outcome_bin ~ age + treatment, data = data, family = binomial)
summary(model_log)

Univariate Regression Screening

Before building a multivariable model, it’s common to screen each predictor on its own first. gtsummary::tbl_uvregression() fits one regression per predictor and lays the results out in a single comparison table.

data$bmi <- rnorm(100, 27, 4)

tbl_uvregression(
  data[, c("blood_pressure", "age", "treatment", "bmi")],
  method = lm,
  y = blood_pressure,
  hide_n = TRUE
)
Characteristic Beta 95% CI p-value
age 0.07 -0.21, 0.35 0.6
treatment


    A — —
    B -3.8 -9.5, 2.0 0.2
bmi 0.40 -0.29, 1.1 0.3
Abbreviation: CI = Confidence Interval

Each row is its own simple regression, fit independently — this is a screening step, not a substitute for the multivariable model above, since it ignores confounding between predictors.

Cox Proportional Hazards Regression

For time-to-event outcomes (e.g. time to recovery, time to relapse), use survival::coxph() instead of lm()/glm(). It models the hazard of the event happening at any given time, adjusted for covariates.

library(survival)

data$time  <- rexp(100, rate = 0.05)
data$event <- rbinom(100, 1, 0.7)   # 1 = event observed, 0 = censored

cox_model <- coxph(Surv(time, event) ~ age + treatment, data = data)
summary(cox_model)

exponentiate = TRUE reports hazard ratios: above 1 means a faster time-to-event (higher instantaneous risk) as the predictor increases, below 1 means a slower one.

fit <- survfit(Surv(time, event) ~ treatment, data = data)
plot(
  fit, col = c("#3498db", "#e74c3c"), lwd = 2,
  xlab = "Time", ylab = "Survival probability",
  main = "Kaplan-Meier Curves by Treatment"
)
legend("topright", legend = c("Treatment A", "Treatment B"),
       col = c("#3498db", "#e74c3c"), lwd = 2)

The Kaplan-Meier curve shows the estimated probability of not yet having experienced the event over time for each treatment group — a purely descriptive view, independent of the Cox model’s covariate adjustment above.

Model Diagnostics with performance

The performance package gives a quick, standardized diagnostic check for a fitted model, going further than the base-R diagnostic plots used earlier.

library(performance)

check_model(model)
r2(model)
# R2 for Linear Regression
       R2: 0.017
  adj. R2: -0.003
check_collinearity(model)
# Check for Multicollinearity

Low Correlation

      Term  VIF    VIF 95% CI adj. VIF Tolerance Tolerance 95% CI
       age 1.03 [1.00, 19.42]     1.02      0.97     [0.05, 1.00]
 treatment 1.03 [1.00, 19.42]     1.02      0.97     [0.05, 1.00]

check_model() bundles several checks — linearity, homogeneity of variance, normality of residuals, influential observations, and collinearity — into one panel. check_collinearity() reports Variance Inflation Factors (VIF) on their own; values above roughly 5 suggest predictors are too correlated with each other to interpret their individual coefficients reliably.
