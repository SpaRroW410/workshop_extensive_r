Introduction to R

Gateway to Statistical Compuing

R - Language

  • Developed in the early 1990s
    -Ross Ihaka and Robert Gentleman at the University of Auckland, New Zealand
  • A powerful language for statistical computing and graphics
  • Widely used by statisticians, data scientists, and researchers
  • RStudio: User Interface

Why Use R

  • Extensive libraries for data analysis and visualization
  • Active community support
  • Cross-platform compatibility (Windows, MacOS, Linux)
  • Integration with Python and C++
  • Free and open-source

Key Features of R

  • Comprehensive statistical analysis tools
  • Advanced graphics capabilities with ggplot2
  • Rich ecosystem of packages (dplyr, tidyr)
  • Interactive and reproducible research with RMarkdown or Quarto

R vs Python

R

  • Designed for statistical analysis and visualization
  • Rich ecosystem: dplyr, ggplot2, caret
  • Preferred in academia and research

Python

  • General-purpose language
  • Strong in data science and ML: pandas, scikit-learn, TensorFlow
  • Versatile for web, automation, and more

Variables and Data Types

  • Numeric — numbers such as 3.14, 42
  • Integer — whole numbers with L suffix, e.g. 5L
  • Character — text values like "data"
  • Logical — TRUE or FALSE
  • Factor — categorical values with levels
  • Complex — numbers with imaginary parts like 1 + 2i
Show the code 
x <- 5          # numeric
name <- "Alice" # character
flag <- TRUE    # logical
colors <- factor(c("red", "blue", "green"))
  • Variables store values in memory and can be reused later
  • R is dynamically typed: type depends on the stored value

Vectors and Sequences

  • Create ordered collections with c() and sequences with seq()
  • Useful for numeric data, indexes, and repeated values
Show the code 
ages <- c(23, 35, 28)
seq(1, 100, 3)
seq(1, 2, length.out = 10)

Factors and Categorical Variables

  • Store categories or groups with fixed levels
  • Important for statistical modeling and reporting
  • Use factor() to make discrete labels or ordered categories
Show the code 
gender <- factor(c("Male", "Female", "Male", "Female"),
                 levels = c("Male", "Female"))
physical_activity <- factor(sample(c(1, 2), 10, replace = TRUE),
                            levels = c(1, 2),
                            labels = c("Yes", "No"))

Lists and Matrices

Lists

  • Store mixed types in one object
  • Can contain vectors, data frames, functions, or other lists
  • Good for nested results and complex outputs
Show the code 
my_list <- list(name = "Alice", score = 95, data = c(1, 2, 3))

Matrices

  • Two-dimensional arrays with a single data type
  • Ideal for numeric calculations, matrices, and linear algebra
  • Built from vectors using matrix(), cbind(), or rbind()
Show the code 
m <- matrix(1:9, nrow = 3)

Data Structures

  • Data frames are the most common table structure in R
  • They combine columns of equal length and can contain different types
  • Lists and matrices are also important foundational structures
Show the code 
my_data <- data.frame(
  ID = 1:5,
  Name = c("Alice", "Bob", "Charlie", "David", "Eva"),
  Age = sample(20:50, 5, replace = TRUE)
)

Functions and Control Flow

  • Functions are reusable blocks of code created with function()
  • Control flow uses if, else, for, while and repeat
Show the code 
add <- function(a, b) {
  result <- a + b
  return(result)
}

if (add(2, 3) > 4) {
  print("Yes, it is greater than 4")
}
  • Functions help organize logic and avoid repetition
  • Control flow enables conditional decisions and loops

Packages

  • Collections of functions, data, and compiled code
  • Installation:
Show the code 
  install.packages(c("tidyverse", "ggplot2", "readxl", "gtsummary", 
                     "ggstatsplot", "flextable", "pacman"))

Installation

  • Install a single package:
Show the code 
install.packages("dplyr")
  • Install several packages:
Show the code 
install.packages(c("tidyverse", "ggplot2", "readxl"))
  • Use pacman to install and load packages automatically:
Show the code 
if (!require("pacman")) install.packages("pacman")
pacman::p_load(tidyverse, ggplot2, readxl, gtsummary, ggstatsplot, flextable)
  • pacman::p_load() installs missing packages and loads them in one command.
