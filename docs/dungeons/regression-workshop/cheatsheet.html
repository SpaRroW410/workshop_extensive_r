Regression Interpretation Cheat Sheet

Linear and logistic regression · NCD survey examples · print on 2 pages (A4)

1 · Linear regression — reading the output

Output Reads as Example (adjusted SBP model)
β (slope) Change in mean outcome per 1-unit rise in x, others held constant — always give units 1.8 mmHg per g/day
Intercept Mean outcome when all x = 0 — often meaningless (age 0?) so centre x lm(sbp ~ I(age-50)): intercept = SBP at age 50
Categorical β Difference vs the reference level Men vs women: 3.8 mmHg
95% CI Plausible values of the true β 1.2 to 2.4
p-value Chance of data this extreme if true β = 0 — not effect size < 0.001
R² / adj. R² Share of variability accounted for (adjusted penalises extra terms) 0.39 / 0.37
Residual SE Typical prediction miss, in outcome units 13.5 mmHg
CI vs PI CI = mean of a group; PI = a new individual (wider) predict(m, interval = "confidence" / "prediction")

Crude vs adjusted: crude salt β = 3.4 → adjusted 1.8 (a change ≥ 10% ⇒ confounding matters).

Assumptions — plot first, then test

Assumption Check Violation looks like Fix
Linearity Residuals vs x (loess) Curved line Add x², spline, transform
Independence Design; residuals by cluster; ICC Clustered residuals Mixed model, GEE, cluster-robust SE
Normal residuals Q–Q plot Points leave the line Transform, bootstrap (matters for small n)
Equal variance Residuals vs fitted; Breusch–Pagan Funnel Robust SE (vcovHC), transform
Multicollinearity VIF (check_collinearity) VIF > 5–10, β unstable Keep one / combine

performance::check_model(m) · check_normality() · check_heteroscedasticity() · car::vif()

Building the model

  • ✅ Choose covariates from a DAG / theory, fix them before looking at p-values
  • ✅ Report crude and adjusted; state the reference of every factor
  • ⚠️ step() (AIC) = exploration only: biased β, narrow CIs, unstable
  • ⛔ “Univariable p < 0.2 → in the model” can drop real confounders

2 · Logistic regression — reading the output

logit(p) = ln[ p / (1 − p) ] = β₀ + β₁x₁ + …   |   OR = e^β (one-unit change)   |   OR = 1 ⇔ β = 0

Output Reads as Example
β Change in log-odds per 1-unit x 0.214
OR = exp(β) Multiplies the odds by this factor per 1 unit; per k units: OR^k OR 1.24 per g/day; per 5 g = 2.91
95% CI Exponentiate the CI limits of β (so the CI is asymmetric on the OR scale) 1.11 – 1.39
OR > 1 / < 1 Higher / lower odds; CI containing 1 ⇒ not significant
Deviance −2 × log-likelihood (relative to perfect); smaller = better null 687 → 511
LR test Compare nested models: 2×(logLik₁ − logLik₀) ~ χ²(df). Preferred to Wald for model comparison and multi-df terms anova(m0, m1, test = "LRT"), lmtest::lrtest(), drop1(m, test="LRT")
AIC −2 logLik + 2k; lower is better; works for non-nested (same rows!) AIC(m1, m2)
Pseudo-R² McFadden / Nagelkerke / Tjur — not % variance explained; run low; descriptive only 0.26 / 0.38 / 0.29
Calibration Predicted risk ≈ observed risk? Plot deciles; Hosmer–Lemeshow (p > 0.05 OK, but low power/bin-dependent) performance_hosmer(m)
Discrimination AUC = P(random case ranked above random non-case): 0.5 chance · 0.7–0.8 ok · 0.8–0.9 good AUC 0.82 (pROC::roc)

Common outcome? OR ≠ PR

Prevalence 32%. Age 50+ vs <50: OR 5.1 but PR 3.1. OR ≈ PR only if the outcome is rare (< ~10%). For “times as likely”: glm(family = poisson) + lmtest::coeftest(m, vcov. = sandwich::vcovHC(m, "HC0")), or log-binomial.

Write it up

Linear: “Each 1 g/day higher salt intake was associated with a 1.8 mmHg higher SBP (95% CI 1.2 to 2.4), adjusted for age, BMI, sex, residence, education, tobacco, alcohol and physical activity.”

Logistic: “Each 1 g/day higher salt intake was associated with 24% higher odds of hypertension (aOR 1.24; 95% CI 1.11–1.39).”

Pitfall checklist

☐ outcome type → model ☐ covariates pre-specified ☐ units + reference stated ☐ CI, not just p ☐ assumptions checked ☐ ≥ 10 events per variable ☐ clustering acknowledged ☐ OR not read as risk ☐ pseudo-R² ≠ R² ☐ association, not causation
