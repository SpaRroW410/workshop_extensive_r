World 1 · The Outcome Detective

What regression is, outcome types, choosing a model, Table 1, missing data

Briefing

Regression describes how the average of an outcome changes with one or more predictors, in real units. The first decision in any analysis is not the software; it is what type of outcome you have.

Outcome → model family: continuous → linear · binary → logistic · count → Poisson / negative binomial · ordered categories → ordinal logistic · unordered categories → multinomial · time-to-event → Cox · clustered or repeated → mixed models / GEE.

Correlation vs regression. Correlation is symmetric and unit-free; regression gives a directional slope in outcome units and can adjust for other variables.

cor(ncd$sbp, ncd$salt_g, use = "complete.obs")
[1] 0.4489003
coef(lm(sbp ~ salt_g, data = ncd))
(Intercept)      salt_g 
 107.420160    3.389337

Missing data. A model silently drops any row with a missing model variable (complete-case analysis), so check missingness before modelling.

ncd |> summarise(across(c(bmi, salt_g, education), ~ sum(is.na(.x))))
# A tibble: 1 × 3
    bmi salt_g education
  <int>  <int>     <int>
1    18     18        15

Level 1 · Roles and types

In the model sbp ~ salt_g + age, which term plays the role of the outcome (dependent variable)?

  • The residual error of the line
  • Participant age in years (age)
  • Daily salt intake (salt_g)
  • Systolic pressure (sbp)

A district programme records how many antenatal visits each woman made (0, 1, 2, …). What type of outcome is this?

  • A count of events
  • A nominal category
  • A continuous measurement
  • A time-to-event outcome

Hypertension (yes/no) will be analysed with age, BMI and salt intake in a cross-sectional survey. Which starting point fits the flowchart?

  • Linear regression because BMI is continuous
  • Logistic regression for the binary outcome
  • Poisson regression because prevalence is a rate
  • Cox regression because age is recorded

Place of delivery is recorded as home, PHC, district hospital or private hospital. Which model family suits this outcome?

  • Negative binomial regression
  • Binary logistic regression
  • Ordinal logistic regression
  • Multinomial logistic model

Level 2 · Reading output

cor(ncd$sbp, ncd$salt_g, use = "complete.obs")
#> [1] 0.449

What does this number tell you?

  • A moderate positive association, but no slope in mmHg per gram
  • Each extra gram of daily salt adds 0.449 mmHg to systolic pressure
  • Salt intake causes about 45% of all the hypertension in the sample
  • Salt intake explains 44.9% of the variation in systolic pressure

ncd has 600 rows. bmi is missing for 18 people and salt_g for a different 18 people (no overlap). How many people stay in a model that uses both?

Level 3 · Workflow

Put a sensible first-pass analysis in order, from first to last:

  1. Add covariates chosen from a causal diagram
  2. Plot the outcome against the main exposure
  3. Fit the crude model and read the slope in its units
  4. Report estimates with CIs and units
  5. Look at the data: structure, missing values, Table 1
  6. Check the assumptions before trusting the intervals
