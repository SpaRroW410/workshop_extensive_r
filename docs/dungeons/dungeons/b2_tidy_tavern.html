Region 1 · Tidy Tavern

filter, select, mutate, group_by and summarise; pipes, conditions and missing values

Briefing

Read first: Data Wrangling. Five verbs do most of the work: filter() rows, select() columns, mutate() new columns, group_by() + summarise() summaries, arrange() order. The pipe |> (or %>%) passes the result of one step into the next.

ncd |>
  filter(residence == "Rural", age >= 60) |>      # comma = AND
  group_by(sex) |>
  summarise(n = n(), mean_sbp = mean(sbp, na.rm = TRUE)) |>
  arrange(desc(mean_sbp))
# A tibble: 2 × 3
  sex        n mean_sbp
  <fct>  <int>    <dbl>
1 Male      22     147.
2 Female    36     142.

Conditions. , or & means AND, | means OR, %in% c(...) means “one of these”. Missing values make a mean NA unless you add na.rm = TRUE. case_when() checks conditions from the top and uses the first that is true.

ncd |>
  mutate(bp_cat = case_when(sbp >= 140 ~ "High", sbp >= 120 ~ "Elevated", TRUE ~ "Normal")) |>
  count(bp_cat)
# A tibble: 3 × 2
  bp_cat       n
  <chr>    <int>
1 Elevated   271
2 High       192
3 Normal     137

Coding tasks in this world are checked without running R: pipes or nested calls, intermediate objects and your own column names all count, as long as the result would be the same.

Level 1 · Rows and conditions

filter(ncd, residence == "Rural", age >= 60)

Which rows are kept?

  • Only the residence and age columns of ncd
  • Rural adults who are also aged 60 or older
  • Adults aged 60 or older, with residence removed
  • Rural adults, plus anyone aged 60 or older

Which condition keeps the same rows as filter(ncd, phys_act %in% c(“low”, “moderate”))?

  • phys_act == “low” | phys_act == “moderate”
  • phys_act > “low” | phys_act < “moderate”
  • phys_act == “low” & phys_act == “moderate”
  • phys_act == c(“low”, “moderate”)

ncd |> filter(htn == 1) |> nrow() returns 192 and nrow(ncd) returns 600. What percentage of adults are hypertensive? (whole number)

Level 2 · New columns and summaries

ncd |> mutate(bp_cat = case_when(sbp >= 140 ~ "High", sbp >= 120 ~ "Elevated", TRUE ~ "Normal"))

What does an adult with sbp = 150 get?

  • NA, because 150 meets more than one of the conditions
  • Both labels, joined together as High and Elevated
  • High, because the first condition that is true wins
  • Elevated, because the last condition that is true wins
ncd |> group_by(sex) |> summarise(m = mean(bmi))
#> sex        m
#> Female    NA
#> Male      NA

What is the most likely reason, and the fix?

  • bmi is stored as a factor; rename the column before averaging
  • Means cannot be grouped by sex; use two separate filters instead
  • Some bmi values are missing; add na.rm = TRUE inside mean()
  • group_by() removed the bmi column; move it after summarise()

Order these steps to get the mean SBP of rural adults for each sex, highest mean first:

  1. arrange(desc(mean_sbp))
  2. ncd |>
  3. filter(residence == “Rural”) |>
  4. group_by(sex) |>
  5. summarise(mean_sbp = mean(sbp)) |>

Level 3 · Write the pipeline

Task: from ncd, keep rural adults aged 40 to 59 (both included), and keep only the columns id, age and sbp.

Task: add a column called bmi_cat to ncd that is “Obese” when bmi is 30 or more and “Not obese” otherwise.

Boss · The full pipeline

Boss: among adults who do not use tobacco, give for each education level the number of people and their mean SBP (ignoring missing values), sorted from the highest mean SBP to the lowest.
