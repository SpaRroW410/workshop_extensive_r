Region 2 · Table 1 Forge

Describing the sample with gtsummary, and reading and critiquing Table 1

Briefing

Read first: gtsummary Tables. Table 1 describes who was studied, overall and usually by group. Effect estimates and models belong in later tables.

ncd |>
  mutate(htn = factor(htn, 0:1, c("No", "Yes"))) |>
  select(age, sex, residence, bmi, sbp, tobacco, htn) |>
  tbl_summary(by = htn, statistic = list(all_continuous() ~ "{median} ({p25}, {p75})"), missing_text = "Missing") |>
  add_overall() |> add_p() |> bold_labels()

Good Table 1 practice. n (%) for categories; mean (SD) or median (IQR) for numbers, and say which in a footnote; skewed variables get the median. Show missing counts. In a randomised trial do not test baseline differences (they are chance). Coding tasks use tbl_summary(by = ...), add_overall() and add_p().

Level 1 · Purpose and summaries

What is the purpose of Table 1 in a research paper?

  • To list every variable that was collected in the study
  • To show the results of the regression models
  • To describe the sample, overall and by group
  • To report the main effect estimates of the study

Triglyceride levels are strongly right-skewed. How should Table 1 summarise them?

  • The minimum and the maximum, because they cover every value
  • The number of participants, since a skewed variable has no centre
  • Median with the 25th and 75th percentiles, and a footnote
  • Mean with the standard deviation, as for all of the other variables

Among 240 adults, 87 are current tobacco users. What percentage is that, rounded to a whole number? (whole number)

Level 2 · Reading and pitfalls

In a randomised trial, Table 1 shows p-values comparing baseline characteristics between the two arms. What is the problem?

  • Any baseline difference arises by chance, so tests answer little
  • Baseline tests are required, and a significant result proves bias
  • The p-values are too large because randomisation removes all differences
  • Table 1 may contain just the variables measured after treatment

A Table 1 row reads: Age, years — 52 (41, 63). The footnote says ‘Median (IQR)’. How should it be read?

  • The mean age is 52 and the standard deviation is between 41 and 63
  • Half are younger than 52; the middle half are aged 41 to 63
  • Every participant is aged between 41 and 63 and the average is 52
  • The age was recorded as 52 for the group, with a range of 41 to 63

BMI is missing for 18 of 600 participants. How should Table 1 handle this?

  • Leave the missing values out of the table without saying so
  • Remove all 18 participants from every row of the table
  • Replace them with the average BMI so that the table has no gaps
  • Show the number missing for BMI, and the number analysed

Boss · Critique a Table 1

Boss: flag every flawed statement in this Table 1 write-up (observational study of 600 adults).

  • Continuous variables are shown as mean (SD) or median (IQR), and the footnote says which.
  • Skewed triglycerides are summarised by mean and SD for consistency with the other rows.
  • The number of missing values is shown for each variable that has any.
  • The table reports the odds ratio for hypertension for every variable listed.
  • Categorical variables are shown as n (%) within each group.
  • The footnote names the test behind each p-value.
