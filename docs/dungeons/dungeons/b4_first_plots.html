Region 1 · First Plots

The grammar of graphics; choosing a histogram, bar chart, box plot or scatter plot

Briefing

Read first: Grammar of Graphics and the Basic Plot Gallery. A ggplot is data + aesthetic mappings (aes(): which variable goes to x, y, colour) + geoms (the marks), plus labels, facets and themes.

ggplot(ncd, aes(x = salt_g, y = sbp, colour = sex)) +
  geom_point(alpha = 0.6) +
  facet_wrap(~ residence) +
  labs(x = "Salt intake (g/day)", y = "Systolic BP (mmHg)")

Choose by variable type. One continuous variable: histogram. Counts of a category: bar chart. A continuous variable across groups: box plots. Two continuous variables: scatter plot. Put a fixed colour outside aes(); inside, it is treated as data.

Level 1 · Which plot?

You want to show how many adults are in each education level. Which plot fits best?

  • A histogram of the education level of each adult
  • A bar chart with one bar per education level
  • A line chart joining the education levels in order
  • A scatter plot of education level against id

You want to compare the spread of systolic BP across the four education levels. Which plot fits best?

  • A box plot of SBP for each education level
  • A single histogram of SBP for the whole sample
  • A bar chart of the number of adults per level
  • A pie chart of the mean SBP of each education level

In ggplot(ncd, aes(x = age, y = sbp)) + geom_point(), what does the aes() part do?

  • It draws one point for every row of the data in the plot
  • It filters ncd to the two columns that are used
  • It maps age to the x position and sbp to the y position
  • It chooses the colours and the theme used for the plot

Level 2 · Grammar details

ggplot(ncd, aes(age, sbp)) + geom_point(aes(colour = "blue"))

What do you get?

  • Blue points with no legend, as the code intends
  • An error, because colours cannot go inside aes()
  • Points coloured by a variable in ncd called blue
  • One default colour, plus a legend labelled blue

What does adding + facet_wrap(~ residence) to a scatter plot of age against sbp do?

  • It colours the points by residence in one shared panel
  • It splits the plot into small panels, one per group
  • It drops the adults whose residence value is missing
  • It adds a separate trend line for each residence group

Put the layers of a ggplot in the order you usually write them:

  1. Finish with a theme, such as theme_minimal()
  2. Map variables to x, y and colour with aes()
  3. Start with ggplot() and the data
  4. Add the geometric layer, such as geom_point()
  5. Add labels for the axes and title with labs()
