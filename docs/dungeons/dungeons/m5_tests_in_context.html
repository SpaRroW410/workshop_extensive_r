Region 2 · Tests in Context

Choosing between tests, checking assumptions, paired data, multiple testing and effect sizes

Briefing

Read first: Test Selection Guide and Data Analysis. Region 1 asked “which test?”; here the question is “which test, given this data, and what do I report?”. The file bp_followup (120 people measured twice) has a download button on the questions that use it.

fu <- read_csv(c("../data/bp_followup.csv", "data/bp_followup.csv")[file.exists(c("../data/bp_followup.csv", "data/bp_followup.csv"))][1], show_col_types = FALSE)
t.test(fu$sbp_followup, fu$sbp_baseline, paired = TRUE)           # the same people twice: paired

Decisions. Skewed outcome + small groups: Wilcoxon / Kruskal-Wallis. Same people twice: paired. Four groups: one overall test first, then adjusted pairwise tests. Small expected counts: Fisher. Many tests: adjust (Bonferroni = divide the level by the number of tests). Always give the difference with its 95% CI, not only p.

Level 1 · Choosing

Length of hospital stay is strongly right-skewed and each of two groups has only 15 patients. Which comparison is the most suitable?

  • A two-sample t-test on the means, with no further checks
  • A Wilcoxon rank-sum test, which compares ranks and not means
  • A paired t-test, because both groups have 15 patients
  • A chi-square test, after cutting the stay into short and long

You want to compare mean SBP across four education groups. Why start with one overall test (ANOVA or Kruskal-Wallis) rather than six t-tests?

  • The overall test needs no assumptions about the data at all
  • Six tests would give exactly the same p-value as one test
  • Each extra test adds a chance of a false positive
  • A t-test cannot compare any two groups that have unequal sizes

SBP was measured in the same 120 people at baseline and again after 6 months. Which analysis fits?

  • A chi-square test comparing baseline against follow-up SBP
  • A paired t-test (or signed-rank test) on the differences
  • A two-sample t-test comparing the baseline and follow-up groups
  • A one-way ANOVA with baseline and follow-up as two groups

Level 2 · Details

You plan 5 hypothesis tests and want an overall significance level of 0.05 using the Bonferroni method. What is the significance level for each single test? (2 decimals)

A 2 × 2 table of a rare outcome has expected counts of 1.8 and 3.2 in two of its cells. Which test should you use?

  • A paired t-test, because the table has two rows
  • Fisher’s exact test, because the expected counts are small
  • No test is possible when a cell is small, so none is run
  • The chi-square test, since it is the usual test for tables

A report says ‘SBP was significantly lower in the intervention group (p = 0.03)’. What is missing that a reader needs most?

  • The size of the difference and its 95% confidence interval
  • The name of the statistical program that produced the p-value
  • A second and smaller p-value from a different type of test
  • The sentence that the result proves the intervention works
