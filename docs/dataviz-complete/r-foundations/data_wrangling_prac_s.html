Exercise 3

Create a new column bmi_group where BMI is classified as:

  • <25 = "Normal"
  • 25 to <30 = "Overweight"
  • >=30 = "Obese"
Show the code 
clinic_wide %>%
  mutate(
    bmi_group = case_when(
      bmi < 25 ~ "Normal",
      bmi >= 25 & bmi < 30 ~ "Overweight",
      bmi >= 30 ~ "Obese"
    )
  )
